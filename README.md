# Aura Retail

Hardware e-commerce storefront with reviews, cart, and an admin dashboard for catalog, stock and order analytics.

## Planned features
- Catalog with category filter, search and sort
- Product pages with specs, stock status, rating breakdown and reviews
- Cart and mock checkout that writes orders and decrements stock
- Admin dashboard: catalog, stock adjustments, orders, analytics
- Teal (#008080) design system with dark/light theme

## Stack
Next.js (App Router), TypeScript, Tailwind CSS, Drizzle, Neon Postgres, Netlify
